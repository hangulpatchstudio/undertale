# 언더테일 한글패치 — 지난 버전

[한글패치스튜디오](https://hangulpatchstudio.com/g/undertale)에 올라온 **언더테일** 한글패치의 **지난 버전** 보관소입니다.

- **최신 버전과 적용 방법은 [한글패치스튜디오 게임 페이지](https://hangulpatchstudio.com/g/undertale)에서 받으세요.**
- 지난 버전은 오른쪽 **Releases** 에 있습니다. 가지고 있는 게임 버전에 맞는 것을 고르세요. 각 릴리스에 배포 번호·게임 버전·번역 단계·SHA-256 을 적어 두었습니다.
- 오류·오역 제보는 [게임 페이지](https://hangulpatchstudio.com/g/undertale)의 버그리포트·댓글로 남겨 주세요.

비공식 팬 제작물입니다. 게임과 이미지의 권리는 각 권리자에게 있습니다.
